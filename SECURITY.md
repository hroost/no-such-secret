# Security policy

Please report vulnerabilities privately using this repository's GitHub Security Advisory reporting channel. Do not open a public issue or include proof-of-concept secrets in a pull request.

Reports should include the affected version/commit, impact, reproduction steps, and any mitigation already known. We will acknowledge reports promptly, coordinate a fix and release, and request confirmation before public disclosure.

The supported version is the latest version on the `master` branch until the project publishes stable release lines.
